# StockPredict

台股與美股的股價研究工具。提供繁體中文／英文切換、歷史價格圖、1–30 個工作日的走勢估計、波動情境帶，以及逐日重新訓練的歷史回測。使用 FastAPI、NumPy 與原生 JavaScript，行情分析無需資料庫、API 金鑰或前端建置工具。

新增瀏覽統計與僅站主可查看的建議表單。這兩項功能需連接持久資料庫，免費方案設定步驟見 [NEON_SETUP.md](NEON_SETUP.md)。尚未設定時會顯示未啟用；中英文切換與行情分析可獨立使用。

## 啟動

需要 **Python 3.12 或 3.13** 和 [uv](https://docs.astral.sh/uv/)。在專案目錄執行：

```bash
uv sync --locked --dev
uv run --no-sync uvicorn stockpredict.main:app --host 0.0.0.0 --port 8000
```

服務在 8000 埠提供網頁；`/docs` 是 API 文件。開發時可在啟動指令最後加上 `--reload`。健康檢查：

```bash
curl --fail http://127.0.0.1:8000/api/health
```

雲端工作階段使用既有 `/workspace/StockPredict` checkout，不需建立額外 worktree。工作階段重啟後，重新執行上述啟動指令；不要假設服務程序會隨環境快照保留。

## 資料來源

- **示範資料（預設）**：2330.TW、0050.TW、AAPL、MSFT 的可重現合成資料，約一年的工作日。所有價格、回測與預測均非真實市場表現。無需外部網路。
- **證交所（上市）**：透過台灣證券交易所 `STOCK_DAY` API 取得數字代碼的上市股票與 ETF 每日收盤價，例如聯電 `2303`／`2303.TW`、台積電 `2330.TW`、`0050.TW`。不需 API 金鑰，也不依賴 Yahoo。向前取得最多六個月、目標至少 100 筆資料；最低需要 60 筆。上櫃 `.TWO`、英文字尾 ETF 及美股請使用其他來源。資料未還原權息。當天資料只在台北時間 **15:00 起**且來源已公布有效收盤價時納入；15:00 是本工具的保守門檻，不代表證交所保證公布時間。環境需允許 `www.twse.com.tw`。
- **CSV**：上傳自己的歷史收盤價，伺服器不將檔案寫入磁碟。使用 UTF-8 編碼（接受 BOM），欄位為 `Date,Close`（大小寫不限，可有額外欄位），日期嚴格使用 `YYYY-MM-DD`。至少 60、最多 5,000 筆，上限 2 MB。可由新至舊排列，系統會排序；重複日期、空值、非有限數值或非正價格會拒絕。價格支援 0.00000001 至 1,000,000,000,000。
- **Yahoo 每日行情（選用）**：讀取 `query1.finance.yahoo.com`，需環境允許此 HTTPS 網域。不需 API 金鑰。來源可能限流或拒絕存取；失敗時顯示錯誤，不會偷偷換成示範價格。當天日線只在來源提供有效的當日交易時段、依交易所當地時間已收盤至少 **15 分鐘**，且回應包含當天有效價格時納入。使用來源的收盤時間處理美股夏令時間與提早收盤；缺少或無效的交易時段資訊時，仍排除今天。這是未還原權息的每日資料，**不是即時報價**；公司行動可能造成價格跳空、扭曲回測。

CSV 範例格式（實際分析需至少 60 筆）：

```csv
Date,Close
2025-01-02,100.5
2025-01-03,101.2
2025-01-06,100.9
```

台股上市代號可用 `2330.TW`，上櫃代號如 `6488.TWO`；美股如 `AAPL`、`MSFT`。示範模式僅提供上述四檔，其餘依市場選擇證交所、CSV 或 Yahoo。CSV 的幣別、交易日完整性與權息調整方式由使用者確認；每一列視為一個觀測日。

聯電可直接點網頁「聯電 2303」，會明確選用證交所來源。Yahoo 出現 HTTP 429 時，上市台股會顯示「改用證交所資料」按鈕，須由使用者選擇，失敗時不會偷偷換成其他來源。錯誤提示會列出目前保留的舊結果代號與來源，避免將舊結果誤認成新分析。

首次讀取證交所資料可能需要 20–60 秒。每個程序內的上游請求至少間隔 3 秒；一般成功資料快取 1 小時且不跨台北日期，跨過 15:00 門檻時會重新讀取。平日盤後尚未取得當天有效收盤價時，成功資料最多快取 5 分鐘，錯誤冷卻 60 秒。快取各限制 64 檔，會合併重複請求；忙碌時回報稍後再試，不讓請求無限等待。快取不持久儲存，也不在更新失敗時回傳過期價格。這些措施降低請求量，但無法保證上游永遠可用。

點擊「開始分析」會依上述快取規則查詢資料，網頁不會在背景定時更新。休市、停牌或來源尚未公布時，結果保留來源實際可用的最近交易日，請查看「資料截至」日期，勿將最近一筆自動視為今天。未來日期不會納入。

可用 `/?symbol=2303.TW&source=twse&horizon=5` 開啟聯電分析；預設首頁仍顯示合成示範資料。

## 預測與回測

模型 **Ridge AR(5)** 使用最近五個對數報酬率作為輸入，以固定正則化 0.01 的線性迴歸估計下一日報酬率；不使用新聞或基本面。多日預測固定模型係數，將估計值遞迴輸入，且每日估計對數報酬限制在 ±0.2。這個簡單模型方便重現、檢查與替換，不保證優於基準。

- **回測**：取最後 `min(30, 資料筆數 // 5)` 筆，逐筆僅用該日以前的資料重新訓練，計算一日預測 MAE、RMSE、MAPE 與方向命中率。以「下一日價格等於前一日價格」比較 MAE；模型未勝過基準時會明確提示。這不是持續追蹤的實盤績效，也未驗證多日預測表現。
- **方向命中率**：比較預估價格與前日價格的正負方向是否符合實際變動；不變也是獨立方向，因此不變基準僅在實際價格不變時命中。
- **情境帶**：近 60 個對數報酬率的標準差 × `1.645 × √預測步數`，套用於對數價格。使用 252 日年化波動率。此區間沒有校準未來涵蓋率，不應解讀為已驗證的信賴區間。
- **日期**：未來日期僅排除週末，未整合台灣或美國的交易所休市日。

本工具僅供研究與教學，不構成投資建議。

### 聯電的隔夜美股參考（選用）

聯電 `2303`／`2303.TW` 使用證交所或 Yahoo 真實行情時，可勾選「美股參考」，從 Yahoo 取得 **UMC ADR** 與 **SOXX 半導體 ETF** 的每日資料。這裡指台灣夜間的美股正常交易時段，不是期貨夜盤或盤後交易。預設關閉，不需要新帳號、金鑰或付費服務。

新增的單日 Ridge 模型使用五個台股歷史對數報酬，加上兩項隔夜美股對數報酬。模型只對「下一個平日」另提供比較，不修改既有 AR(5) 的圖表或多日路徑，因為未來美股報酬尚未知。參考因子由資料估計，不預設強相關，也不手動固定高權重；面板列出對齊後最近最多 60 筆報酬率的相關係數、樣本數與期間。價格水準的相關與因果或領先效果不能混為一談；ADR 也可能反映台股已發生的行情。

每筆台股目標日以台北 09:00 作為資訊截止，隔夜因子計算前一個台股觀測日 13:30 後至截止前的美股累積報酬。即時查詢還受查詢當下時間限制，未收盤的當晚美股不會被使用。沒有歷史公布時間日誌，因此保守假設美股交易日紐約 16:15 才可用；此時間由交易所時區處理夏令時間，提早收盤日也延後到此門檻。它不是實際逐筆公布時間，歷史行情亦可能經後續修訂，不能將這種時間對齊回測視為完整的歷史資訊版本回放。

本版未導入交易所假日表。缺少應有美國平日資料（包括美國休市或資料缺漏）時，會跳過該回測樣本，或標示當前參考不可用，不將缺值補成零報酬。台股休市後跨多個美股交易日，會累積實際涵蓋區間的報酬。等待當晚收盤、歷史太少、台股資料過期或 Yahoo 限流時，面板清楚顯示狀態，原本的台股分析仍可使用。

至少需要 60 組完整對齊樣本。單日模型固定 Ridge 懲罰 1.0，各次訓練只使用當時歷史前綴的均值與標準差；回測在同一批日期比較跨市場模型、原 AR(5) 與前收盤基準的 MAE，顯示相對 AR(5) 的變化，可能更差。兩模型的標準化、懲罰與訓練樣本設定也不同，差異不能單獨歸因於美股因子。因子資料於伺服器快取 5 分鐘、失敗冷卻 60 秒；不回傳過期因子來冒充更新成功。

## 驗證

```bash
uv run --no-sync pytest -q
uv run --no-sync ruff check .
uv run --no-sync ruff format --check .
node --check stockpredict/static/app.js
node --check stockpredict/static/i18n.js
node --check stockpredict/static/community.js
node --check stockpredict/static/admin.js
```

測試涵蓋 CSV 驗證、數值與日期邊界、回測的時間順序、API、靜態資源與模擬的上游回應，不依賴 Yahoo 連線。相依套件版本由 `uv.lock` 固定。

## API

```text
GET  /api/health
GET  /api/analysis?symbol=2330.TW&source=demo&horizon=5
GET  /api/analysis?symbol=2303&source=twse&horizon=5
GET  /api/analysis?symbol=2303&source=twse&market_context=us_overnight
POST /api/analysis/csv
```

CSV 請求 JSON：`{"symbol":"CUSTOM","horizon":5,"csv":"Date,Close\n..."}`。`horizon` 為 1–30；網頁提供 5、10、20 日快捷選項。回應包含 `history`、`forecast`、`summary`、`backtest`、`model`、`warnings`；百分比欄位單位為百分點（例如 2.5 表示 2.5%）。CSV 不推測幣別。

行情 API 支援 `lang=zh-TW`／`lang=en`（CSV 也用 query 參數）。成功回應另含 `locales` 的雙語說明，前端切換語言時保留既有數值、輸入與圖表，不重新下載行情。語言偏好保存在瀏覽器；也可用 `?lang=en` 開啟。

`market_context=us_overnight` 僅支援真實來源的聯電，回應另含獨立的 `market_context`。其 `status` 為 `ready`、`waiting` 或 `unavailable`，提供因子交易日、假設可用時間、相關性及同期間回測；尚無可用預測時 `forecast` 為 `null`。省略參數不讀取美股參考資料。前端可用 `/?symbol=2303.TW&source=twse&market_context=us_overnight` 預選此功能。

瀏覽／建議 API 位於 `/api/community`，包括 `stats`、`visits`、`comments` 與 Bearer 管理金鑰驗證的 `admin/comments`。私人模式的公開 API 不回傳留言內容或留言數。每次頁面載入使用唯一 ID，重試不重複計數；每個匿名瀏覽器 10 分鐘內最多送出 3 則建議。管理頁位於 `/admin`，不保存金鑰；管理回應禁止快取。

站主管理頁顯示留言總筆數、未處理與已處理筆數，以及目前分類的「已載入／共幾筆」；數量涵蓋所有分頁，刪除後總數會減少。標記處理或刪除後會重新讀取資料庫計數。這些筆數僅透過驗證管理金鑰的 API 提供，公開留言與統計 API 不揭露私人留言數量。

## 專案結構

網站部署方式見 [DEPLOY.md](DEPLOY.md)，附有 Dockerfile 與 Render Blueprint 設定。發布 Codex 開發環境與部署公開網站是分開的步驟。

```text
stockpredict/
  main.py       # HTTP API 與靜態網頁
  data.py       # 示範、CSV 與 Yahoo 資料來源
  twse.py       # 證交所月行情、日期轉換與快取／請求節流
  community.py  # 持久化瀏覽統計與站主私人建議
  localization.py # 行情 API 的中英文說明與錯誤訊息
  forecast.py   # 預測、回測與數值驗證
  overnight.py  # 聯電隔夜因子對齊、相關性與單日比較回測
  market_data.py # 固定美股參考來源的有界快取與失敗處理
  static/       # HTML、CSS、JavaScript 介面
tests/          # 自動化測試
```

本版為個人研究與 Side Project，沒有持倉、交易下單或投資績效保證。訪客不需登入，私人建議由持有管理金鑰的站主查看。行情 CSV 不持久儲存；啟用資料庫後僅瀏覽統計與送出的建議持久保存。正式營運仍需依實際需求管理服務、資料授權與營運監控。
